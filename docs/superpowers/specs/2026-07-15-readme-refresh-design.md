# videoCreaterForAi README 与 Markdown 口播稿文档设计

## 目标

删除原 MoneyPrinterTurbo README 中的宣传、赞助、作品展示、跨平台部署、通用模型列表和历史项目链接，只介绍当前二次开发项目的主要能力与最短使用路径。

README 面向首次接触项目的使用者；独立 Markdown 文档同时面向人工编辑者和负责整理文章的 AI。

## README 结构

README 使用中文，控制在易于快速浏览的长度，包含以下内容：

1. 项目名称 `videoCreaterForAi` 与一句话定位。
2. 主要功能：
   - 上传结构化 Markdown 口播稿直接生成视频；
   - CosyVoice3 本地语音合成；
   - Qwen Aligner 字幕时间轴对齐；
   - Pexels、Pixabay、Coverr 在线素材搜索；
   - 横屏 16:9 素材过滤与尽量不裁剪的画面合成；
   - 底部单行白色黑描边字幕；
   - 同行多重点词、重复重点词、随机颜色/位置/动画和固定音效库；
   - Markdown 流程使用文档内的搜索词与重点词，生成阶段不再调用 LLM。
3. 简要工作流程：准备 Markdown、上传 WebUI、生成旁白和字幕、下载场景素材、合成视频。
4. Windows WebUI 最短启动命令。
5. 示例文件和 Markdown 格式文档链接。

README 不保留原项目徽章、赞助商、旧仓库地址、Docker/Colab/多平台安装说明、通用 AI 服务列表、作品墙、Star History 和旧项目反馈入口。

## Markdown 格式文档

新增 `docs/markdown-script-format.md`，内容包含：

1. 使用场景和 UTF-8 `.md` 文件要求。
2. 唯一允许的结构：一个一级标题和一个固定四列表格。
3. 固定表头：`序号`、`口播文案`、`重点词`、`素材搜索词`。
4. 字段规则：
   - 序号从 1 开始连续递增；
   - 口播文案不能为空；
   - 重点词使用中文或英文分号分隔，且必须出现在同行口播文案中；
   - 素材搜索词使用英文，每行最多 3 个，使用分号分隔；
   - 第一行必须包含素材搜索词；
   - 填写素材搜索词的行开始新场景，后续空白行继续使用该场景，直到下一行出现新的搜索词。
5. 重点词显示规则：同行可包含多个重点词，同一词可在不同文章行重复出现并分别触发。
6. 一份可直接上传的完整示例。
7. 一段可直接复制给 AI 的转换提示词，要求 AI 只输出合规 Markdown，不添加解释、代码围栏或表格外内容。
8. 上传前检查清单和常见错误说明。

## AI 转换提示词要求

提示词指导 AI 将普通文章整理为适合口播和视频素材检索的行级脚本：

- 保留原文核心观点，但允许调整为自然口语；
- 每行表达一个完整、适合字幕显示的语义单元；
- 仅标记确实需要二次强调且存在于同行文案中的重点词；
- 根据连续几句话的共同画面含义划分场景，不要求每行都填写搜索词；
- 每个新场景提供 1 至 3 个具体英文搜索短语；
- 严格使用固定标题和四列表格，不输出附加说明。
